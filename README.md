# FreqMark — Watermarking LLM Text

This is my work on FreqMark, a method to watermark text generated by large language models. I implemented the paper by Victor Sheng, ran attacks, and tested robustness.

## What's inside

- `freqmark_pipeline.ipynb` – main notebook with watermark generation, attacks, and detection.
- `freqmark_snr_results.csv` – SNR values for each sample.
- `freqmark_master_final.csv` – full dataset with texts, labels, z‑scores.
- `freqmark_dataanalysis.ipynb` – extra plots and analysis.

## What I did

1. Reproduced the FreqMark watermark on Llama‑3.2‑1B.
2. Applied attacks: translation, substitution, paraphrasing, mixed text.
3. Computed z‑scores and SNRs for detection.
4. Measured robustness with AUC curves.
